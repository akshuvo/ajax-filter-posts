== Description ==

**Post Grid Master** (GridMaster) is an all-in-one WordPress **post grid, card builder, and AJAX filter plugin**. Design custom post cards visually with Gutenberg blocks, display posts in responsive CSS Grid, List, True Masonry, Metro Mosaic, Carousel, or Vertical Reels layouts, and let visitors filter and search content instantly with zero page reloads.

Built for bloggers, agencies, publishers, and WooCommerce store owners, Post Grid Master works with every WordPress theme, any Custom Post Type (CPT), any custom taxonomy, and all major page builders — without writing PHP templates.

== Installation ==

= Automatic Installation (Recommended) =

1. In your WordPress dashboard, navigate to **Plugins → Add New**.
2. Search for **Post Grid Master**.
3. Click **Install Now**, then click **Activate**.
4. Open **Post Grid Master** in the admin sidebar to create a new grid using a Starter Blueprint, Card Template, or the visual Gutenberg Card Studio.

= Manual Upload via ZIP =

1. Download the plugin ZIP file from WordPress.org and unzip it.
2. Upload the `ajax-filter-posts` directory to `/wp-content/plugins/` via FTP or your hosting file manager (or upload the ZIP directly under **Plugins → Add New → Upload Plugin**).
3. Activate **Post Grid Master** on the **Plugins** screen.
4. Create and save your grid under **Post Grid Master**, then insert it using the Gutenberg block, Elementor/Beaver/Bricks/WPBakery widget, Classic Widget, or `[gridmaster]` shortcode.

== Frequently Asked Questions ==

= How do I create and display my first post grid? =

Open **Post Grid Master** in your WordPress dashboard and create a new grid. You can pick a one-click **Starter Grid Blueprint** (such as SaaS Blog, Editorial Metro, or Masonry Portfolio) or design your card visually in the Gutenberg Card Studio using 17+ dynamic blocks and 18 free card templates. Configure your query, AJAX filters, and pagination, click **Save**, and embed the grid anywhere via the native Gutenberg block, page builder widget, or shortcode.

= Which page builders does Post Grid Master support natively? =

Post Grid Master ships with native widgets, modules, and elements — including saved-grid dropdowns and quick "Edit this grid" links — for **Gutenberg (Block Editor)**, **Elementor**, **Beaver Builder**, **Bricks Builder**, **WPBakery Page Builder**, and **Classic WordPress Widgets**. You can also use shortcodes in Divi, Oxygen, Breakdance, or PHP template files.

= Can I build AJAX-filtered grids for Custom Post Types and Custom Taxonomies? =

Yes. Post Grid Master works with any registered public Custom Post Type (including those created with ACF, CPT UI, Pods, Meta Box, or WooCommerce) and supports single or multi-post-type queries along with any custom taxonomy.

= Can I display custom fields (ACF / Meta Box / native post meta) inside cards? =

Yes. Use the built-in **Post Meta** card block to render any custom field key with custom prefix and suffix labels, or configure the **Featured Image** block to pull image URLs from a custom meta key. In Pro, you can also filter grids by custom fields using the Meta Filter and Numeric Meta Range Slider facets.

= How do I add AJAX Load More or Infinite Scroll pagination? =

Inside your grid's **Pagination** settings, choose between **Numbered AJAX Pagination** (with smart ellipsis), **Load More Button**, or **Infinite Scroll**. All three loading modes work smoothly with AJAX filters without reloading the page.

= Can visitors bookmark or share a filtered grid URL? =

Yes. Post Grid Master supports shareable `gm_*` deep-link URL parameters. When a visitor filters by category, searches, or navigates pages, sharing or reloading that URL restores the exact filtered state automatically.

= Can I place filters in a sidebar or mobile drawer instead of above the grid? =

Yes. Under Layout & Filter Placement, you can position filters at the **Top**, in a **Sticky Left Sidebar**, in a **Sticky Right Sidebar**, or inside an **Off-Canvas Mobile Filter Drawer** with a customizable button label.

= Can I hide filters or remove the "All" button? =

Yes. You can hide filters completely to show a clean post grid, carousel, or masonry layout, or keep taxonomy filters active while hiding the default "All" button.

= Can I use multiple independent post grids on the same page? =

Yes. Every grid maintains its own isolated AJAX state, filters, search input, and pagination so you can display multiple grids on one page without conflicts.

= Can I display Related Posts or replace an Archive layout? =

Yes. The context-aware Query Builder includes **Current Archive** mode (automatically filtering by the viewed category, tag, or taxonomy archive), **Related Posts** mode, and an **Exclude Current Post** toggle for single post templates.

= Can I export a grid from staging and import it on my live site? =

Yes. Use the built-in **JSON Export & Import** feature to download any grid as a portable `.gridmaster.json` file and import its full card design, query, layout, and filter settings onto another WordPress site.

= Will Post Grid Master slow down my WordPress site? =

No. Frontend scripts and stylesheets are registered and enqueued conditionally only on pages that actually render a grid. In addition, the first card's featured image is prioritized to support strong Largest Contentful Paint (LCP) Core Web Vitals scores.

= Does Post Grid Master work with WooCommerce? =

Yes. The free version can query and display `product` posts and `product_cat` / `product_tag` taxonomies. Upgrading to [Post Grid Master Pro](https://addonmaster.com/gridmaster/) unlocks 16 WooCommerce & video card blocks (Price, AJAX Add to Cart, Star Rating, Sale Countdown, Variation Swatches, Quick View, Wishlist, Compare, Request a Quote) and 6 dedicated WooCommerce AJAX filter facets.

= Are my older `[gridmaster]`, `[am_post_grid]`, and `[asr_ajax]` shortcodes still supported? =

Yes. All legacy shortcodes and classic templates remain fully supported alongside the new GridMaster 2.0 visual builder so existing pages continue working smoothly after upgrading.

= Will it work with my WordPress theme? =

Yes. Post Grid Master uses scoped CSS and standard WordPress hooks, making it compatible with block themes (FSE) and classic themes alike, including Astra, Kadence, GeneratePress, Blocksy, OceanWP, Hello Elementor, and default Twenty Twenty-* themes.

= Where can I get support or request a new feature? =

Ask anytime in the [WordPress.org support forum](https://wordpress.org/support/plugin/ajax-filter-posts/) or reach our team directly via [addonmaster.com/submit-a-ticket](https://addonmaster.com/submit-a-ticket/).
